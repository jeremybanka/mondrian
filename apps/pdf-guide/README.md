# The PDF field guide

A small interactive guide to how PDF bytes, objects, page trees, and content streams map to Mondrian’s TypeScript model. The app is private and does not change the published package.

From the repository root:

```sh
pnpm install
pnpm --filter @mondrian/pdf-guide dev
```

The development command builds the workspace’s `mondrian.pdf` dependency before starting Vite. After changing the library, rebuild it to update the guide. The guide’s six chapter URLs use treetrunks for route validation and the browser History API for SPA navigation. Static hosting must rewrite unknown paths to `index.html` so refreshing a chapter URL loads the app.

```sh
pnpm build
pnpm --filter @mondrian/pdf-guide preview
pnpm --filter @mondrian/pdf-guide check
pnpm --filter @mondrian/pdf-guide test
pnpm fmt
pnpm check
```

React renders the guide; atom.io holds the route, specimen controls, and inspector selection; Lasertag scopes each component’s sibling CSS Module; visx supplies scales and SVG geometry. Each chapter has a contents entry, section anchors, and previous/next links. The mobile contents menu and native interactive controls are keyboard accessible. Fonts load from Google Fonts, with system and Georgia fallbacks.

The PDF download, byte offsets, displayed syntax, and object model come from a real five-object PDF generated by the local Mondrian package. The SVG page preview illustrates the specimen’s commands, rather than implementing a general PDF renderer. Moving the rectangle updates the generated stream and download. Tests check parse/serialize behavior, cross-reference offsets, and the chapter routes.

The format explanations connect the PDF object, file, and graphics structure to the local Mondrian implementation. The final chapter links to the [PDF Association specification archive](https://pdfa.org/resource/pdf-specification-archive/), which indexes the PDF 1.7 reference and ISO standards, and Mondrian’s API guide.
